# Яндекс Почта

Настольная почта для macOS и Windows. Показывает папки и пользовательские метки прямо с почтового сервера, умеет читать, искать, отмечать, перемещать и отправлять письма с форматированием и файлами.

Использует те же настройки и защищённо сохранённый пароль, что и `email-cli`.

## Запуск

```sh
pnpm install
pnpm tauri dev
```

## Сборка

```sh
pnpm tauri build
```

Сборку для Windows нужно запускать на Windows, а для macOS — на Mac.
