# Производительность «Яндекс Почты»

## Быстрый прогон

```bash
pnpm perf:cache
pnpm build
```

`perf:cache` измеряет худший локальный полнотекстовый поиск: 100 запросов без совпадений по странице из 60 писем, когда приходится проверить сведения каждого письма.
